# Handry Outlook mobile build

Serve this folder over HTTPS or localhost. The build adds a mobile bottom navigation shell, Plan, Routes, Record, Wind and Friends pages, draggable shaping points plus tap-to-add waypoint editing, local ride recording/history, nearest-point GPX joining, and restored Aeris wind particles.

Important: rotate the Xweather secret and review Firebase/Mapbox key restrictions before public deployment. Ride history and friend shortcuts are stored locally in the browser in this build.
